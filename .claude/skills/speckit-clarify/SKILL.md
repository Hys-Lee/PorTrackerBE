# Speckit Clarify Skill

이 명령은 이 프로젝트에서 아직 안 맞췄다. 도구의 기본 명령은 결과 파일을 `plan.md`·`tasks.md` 로 찾는데, 이 프로젝트는 `design.md`·`task.md` 를 쓰므로 돌리면 없는 파일을 찾는다.

아무것도 쓰지 말고 사람에게 이렇게 알린다: 「이 명령은 이 프로젝트의 단계에 아직 안 맞췄다. 명세·설계·작업 목록·구현 명령을 쓴다.」
